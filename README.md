# Aeon_MQ5_Mod_Piers
Aeon MQ5 MOD for Kodi Piers 22 alpha +

A project to update the Kodi skin Aeon MQ5 for use in Kodi Piers versions from 22. Alpha 1 (nightlies 
since 2024-10-23)
The intent is to provide all functionality of MQ5 on Gotham (ver 2.02) with extensions to incorporate
new capabilities from newer releases of Kodi.  In some cases improvements from MQ5 Gotham will be included.  
Versions of Aeon MQ5 Mod Piers are numbered from 14.8.1.  Stand alone download zip is in the "Releases".
